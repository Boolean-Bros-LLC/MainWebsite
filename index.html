Free tools

— No sign-up, no upload, no catch

Image Shrinker — Web

Compress a photo to an exact size — 20 KB, 100 KB, any target — without uploading it anywhere. The whole compressor runs in your browser tab, which means it still works with the network switched off.

On-device Batch HEIC → JPG EXIF stripped
Open the compressor HEIC converter
What it does
  • — Hits an exact KB target, not a rough guess
  • — JPEG, PNG and WebP output
  • — Strips GPS, capture date and camera details
  • — Free and unlimited, because there is no server
Runs in your browser

Image Resizer — Web

Resize to an exact width and height — 600×600 for a listing, 1080×1080 for a post, 2×2 inch at 300 DPI for an ID form. Same rule as the compressor: the pixels never leave your browser.

Exact W × H Fit or fill Batch HEIC input
Open the resizer 2×2 inch photo
Common targets
  • — 600×600 — avatars, listings
  • — 1080×1080 — Instagram square
  • — 2×2 in @ 300 DPI — 600×600
  • — Any width and height you type
Runs in your browser

Photos → PDF — Web

Combine photos into one PDF without handing your documents to a stranger. JPEGs are embedded byte-for-byte rather than re-compressed, pages can be reordered, and the file is assembled in the tab.

On-device Reorder pages A4 · Letter No re-compression
Make a PDF All PDF tools
Good to know
  • — JPEGs are embedded as-is
  • — PNG and HEIC convert to JPEG once
  • — Auto-orientation per page
  • — The PDF is not smaller than the photos
Runs in your browser

Format converters — Web

PNG and WebP to JPG, at the size you already have. Conversions happen when an app, a form or an email client refuses the format you were given — transparency is flattened onto a colour you pick, and the file is re-encoded in the tab.

[SECTION 03]

The studio.

Boolean Bros LLC is an independent mobile studio run by developers who think in systems. We build focused apps and games — no feature bloat, no dark patterns, no compromises on performance.

Every release ships with clean architecture, precise mechanics and a UI that respects your time. If it doesn't add value, it doesn't ship.

We also publish the tooling we use to ship — release checkers for icons, screenshots, manifests and page sizes — because the boring parts are where apps break. The longer write-ups live at Boolean Build ↗.

Studio philosophy
01 — PRECISION

Every mechanic and interaction is deliberate. We engineer for feel, not just function.

02 — PERFORMANCE

Optimized for every device. No unnecessary dependencies, no lazy rendering shortcuts.

03 — POLISH

The details matter. From frame timing to micro-interactions, every pixel is intentional.
